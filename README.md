# Treatment Journal

A simple personal journal for tracking treatment days: chemo, radiation, scopes and other events, the medicines you took (24-hour time), a 1-5 smiley rating for how you feel, and notes about your day. Entries can be edited, and exported to a spreadsheet (.xlsx).

It is a single static page (`index.html`) with no build step and no server.

## Put it on GitHub

1. Sign in at github.com and choose **New repository**.
2. Name it (for example `treatment-journal`). Choose **Public**, because GitHub Pages on a free account needs a public repository. Create the repository.
3. On the new repository page, choose **uploading an existing file**, drag in `index.html` and `README.md`, and select **Commit changes**.

## Turn it into a website

1. In the repository, open **Settings**, then **Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Set the branch to **main** and the folder to **/ (root)**, then select **Save**.
4. Wait a minute or two. The site address appears at the top of the Pages screen:

   `https://YOUR-USERNAME.github.io/treatment-journal/`

Open that address on any phone or computer. On a phone you can use the browser's "Add to Home Screen" option to keep it handy.

## About your data

- Entries are stored in the browser you use, on that device only. They are never sent to GitHub, and the repository contains no personal information.
- Because the repository is public, anyone with the site address can open the page, but they would only see their own empty journal.
- Clearing browser data, or switching to a different browser or device, means the entries will not be there. Use **Export to spreadsheet** on the Entries page now and then to keep a copy.
